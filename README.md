# รังมด · Delish Foods

ระบบมอบหมายและติดตามงานในธีม "รังมด" (ราชินีมด · หัวหน้ามด · มดงาน) ใช้งานผ่านเว็บ ไม่ต้องมีบัญชี Claude

- **หน้าเว็บ:** ไฟล์เดียว `index.html` ไม่ต้อง build โฮสต์บน Vercel
- **ฐานข้อมูล + ล็อกอิน + แจ้งเตือนสด:** Supabase (Postgres + Auth + Realtime)
- **ความปลอดภัย:** สิทธิ์ทั้งหมดบังคับที่ฐานข้อมูล (Row Level Security) ไม่ใช่แค่ซ่อนปุ่มในหน้าเว็บ

## สิ่งที่ระบบทำ
สมัครสมาชิก (อีเมล+รหัสผ่าน) → ราชินีอนุมัติ → มอบหมายงานรายคน/กลุ่ม/งานประจำ (ทุกสัปดาห์/ทุกเดือน) → อัปเดตความคืบหน้า (มดแบกผัก) → ส่งงานทาง LINE/อีเมล → ตรวจรับ (ผ่าน/แก้ไข/ไม่ผ่าน + น้ำหวาน 1–5 หยด) → ปฏิทิน เตือนความจำ กระดิ่งแจ้งเตือน เสียงเตือน ปุ่มกัด/ตามงานทาง LINE

| ตำแหน่ง | ทำอะไรได้ |
|---|---|
| ราชินีมด | อนุมัติสมาชิก เปลี่ยนตำแหน่ง มอบงานให้หัวหน้า+มดงาน เห็นงานทั้งหมด |
| หัวหน้ามด | มอบงานให้มดงาน |
| มดงาน | รับงาน อัปเดต ส่งงาน |

ทุกคนเห็นเฉพาะงานที่เกี่ยวกับตัวเอง (ราชินีเห็นทั้งหมด)

## ขั้นตอนติดตั้ง (ประมาณ 20–30 นาที)

### 1) สร้างโปรเจกต์ Supabase
1. สมัคร/เข้า https://supabase.com → **New project** (เลือก region ใกล้ไทย เช่น Singapore) ตั้งรหัสฐานข้อมูลแล้วเก็บไว้
2. เมนู **SQL Editor** → New query → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งไฟล์ → **Run** (ต้องขึ้น Success)
3. เมนู **Project Settings → API** คัดลอก 2 ค่า: **Project URL** และ **anon public key**

### 2) ใส่ค่าในโปรเจกต์
เปิดไฟล์ `config.js` แล้วแทนที่ `YOUR-PROJECT-REF` และ `YOUR-ANON-PUBLIC-KEY`
> ใส่ได้เฉพาะ **anon key** เท่านั้น ห้ามใส่ `service_role` key

### 3) อัปขึ้น GitHub
```bash
cd antnest
git init
git add .
git commit -m "รังมด v1"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/antnest.git
git push -u origin main
```
(สร้าง repo เปล่าบน github.com ก่อน แนะนำตั้งเป็น **Private**)

### 4) Deploy บน Vercel
1. https://vercel.com → **Add New → Project** → Import repo `antnest`
2. Framework Preset: **Other** · ไม่ต้องใส่ Build Command / Output Directory → **Deploy**
3. ได้ลิงก์ เช่น `https://antnest-xxxx.vercel.app`

### 5) ตั้งค่า Auth ใน Supabase (สำคัญ)
**Authentication → URL Configuration**
- **Site URL:** ลิงก์ Vercel ของคุณ
- **Redirect URLs:** เพิ่มลิงก์เดียวกัน (ใช้สำหรับลิงก์ยืนยันอีเมล/รีเซ็ตรหัสผ่าน)

**Authentication → Providers → Email**
- เปิด **Confirm email** ไว้ (แนะนำ) ผู้สมัครต้องกดลิงก์ในอีเมลก่อนเข้าสู่ระบบ
- Supabase ส่งอีเมลได้จำกัดจำนวนต่อชั่วโมงในแผนฟรี ถ้าสมัครพร้อมกันหลายคนให้ตั้ง SMTP ของบริษัท (Authentication → SMTP Settings)

### 6) เริ่มใช้งาน
1. **เปิดลิงก์แล้วสมัครเป็นคนแรกทันที** — คนแรกของระบบจะเป็น **ราชินีมด** อนุมัติอัตโนมัติ
2. แจ้งลิงก์ให้ทีม ทุกคนสมัครเอง → ราชินีเข้าเมนู **จัดการรัง** เพื่ออนุมัติและกำหนดตำแหน่ง

> ถ้าคนอื่นสมัครก่อนคุณ เขาจะกลายเป็นราชินี แก้ได้โดยลบผู้ใช้นั้นใน Authentication → Users แล้วลบแถวในตาราง profiles ที่เหลือ (หรือรันใหม่ใน DB ว่าง)

### 7) (ทางเลือก) สร้างงานประจำอัตโนมัติทุกวัน
ปกติระบบสร้างงานประจำรอบใหม่ตอนมีคนเปิดแอป (ล่วงหน้า 6 วัน/14 วัน) ถ้าอยากให้สร้างแม้ไม่มีใครเปิด:
Database → Extensions → เปิด **pg_cron** แล้วรันใน SQL Editor:
```sql
select cron.schedule('antnest-recurring','5 17 * * *','select public.generate_recurring()');
```
(17:05 UTC = 00:05 น. เวลาไทย)

## ปรับแต่ง
- **ตำแหน่งงาน/แผนก:** ค้นหา `const POS=` ใน `index.html` (รูปแบบ `ตำแหน่ง|แผนก` คั่นด้วยจุลภาค)
- **สีแบรนด์:** ตัวแปร `--br`, `--side` ที่ต้นไฟล์ `index.html`
- **ข้อความ LINE:** ค้นหา `msgFollow`, `msgBite`, `msgSubmit`
- **ข้อความแจ้งเตือน:** อยู่ในฟังก์ชัน trigger ของ `schema.sql` (`trg_task_notify` ฯลฯ)

## ข้อจำกัดที่ควรรู้
- ปุ่ม LINE เปิดแอป LINE พร้อมข้อความ ผู้ใช้กดส่งเอง (ส่งอัตโนมัติต้องใช้ LINE Messaging API เพิ่มเติม)
- ส่งงานทางอีเมลเปิดแอปเมลพร้อมข้อความ ผู้ใช้เลือกผู้รับเอง
- เสียงเตือน/เตือนความจำตามเวลา ทำงานตอนเปิดหน้าเว็บอยู่ (ยังไม่ใช่ push notification บนมือถือ)
- งานรอบใหม่จะสร้างล่วงหน้าตามวันที่เลือก วันที่ 29–31 เลือกไม่ได้ ใช้ "สิ้นเดือน" แทน

## ข้อมูลส่วนบุคคล (PDPA)
ระบบเก็บ ชื่อ อีเมล ตำแหน่ง แผนก LINE ID ของพนักงาน ควรแจ้งวัตถุประสงค์ให้พนักงานทราบ กำหนดผู้ดูแลระบบที่เข้า Supabase Dashboard ได้ (คนเหล่านี้อ่านข้อมูลทั้งหมดได้) เปิด 2FA บัญชี Supabase/GitHub/Vercel และตั้ง repo เป็น Private

## ทดสอบอะไรไปแล้ว
- `schema.sql` ทดสอบกับ Postgres จริง 41 ข้อ: สมัครแล้วคนแรกเป็นราชินี ผู้สมัครอนุมัติตัวเองไม่ได้ มอบงานตามลำดับตำแหน่ง ต่างคนต่างเห็นเฉพาะงานตัวเอง ผู้รับงานให้คะแนน/ปิดงาน/แก้รายละเอียดเองไม่ได้ แจ้งเตือนอัตโนมัติ น้ำหวานเฉลี่ย งานประจำไม่สร้างซ้ำ เตือนความจำเป็นส่วนตัว
- หน้าเว็บทดสอบกับ Supabase จำลอง 17 ข้อ (เข้า/ออกระบบ สมัคร อนุมัติ มอบงานกลุ่ม กัด ตรวจรับ งานประจำ เตือนความจำ)
- **ยังไม่ได้ทดสอบกับ Supabase/Vercel จริง** (ผมไม่มีสิทธิ์เข้าบัญชีของคุณ) ส่วนที่ต้องลองจริงคือ อีเมลยืนยัน/รีเซ็ตรหัสผ่าน และการแจ้งเตือนสด (Realtime) ข้ามเครื่อง
